### #1 (P3) — pii-redaction `GOAL.md` frontmatter field name mismatch

- **Where**: `docs/features/pii-redaction/GOAL.md:7`
- **Issue**: `prs: [c08b8fa, 79adc0d, 6147c9e]` lists **commit SHAs** under a `prs:` field. `GOAL-COMPOSER.md` documents `prs:` as PR numbers fetched via `gh pr view <n>`, which silently fails on raw SHAs.
- **Fix**: Renamed field to `commits:` (honest about what's there). Updated `GOAL-COMPOSER.md` schema table + template to document `commits:` as a fallback when feature pre-dates clean PR mapping.

### #2 (P2) — META-JUDGE divergence ceiling

- **Where**: `docs/verify/META-JUDGE.md:91-98`
- **Issue**: META-JUDGE's "default STILL_MOVING on invalid JSON" + the self-acknowledged "META-JUDGE 一直 STILL_MOVING 但 loop 原地转" failure mode created an unbounded divergence path. The escape hatch ("人工偶尔 wc -l") is hand-waved.
- **Fix**: Added **orchestrator-level divergence detector** in `META-JUDGE.md` and gated its invocation in `RUN-VERIFY-LOOP.md` Step 5a (runs **before** META-JUDGE). Detector is content-based, not count-based: if last K (default 3) iterations have `code_diff_summary` in `{"none", "", "no logic change"}` or near-identical, force `decision = STUCK_REPEATING` regardless of META-JUDGE output. This stays consistent with the "no hardcoded N cap" design pillar — the K is a content-similarity window, not an iteration limit.

### #3 (P3) — kind composition source attribution

- **Where**: `docs/features/real-time-intercept/last-verified.md:15` and `docs/features/real-time-intercept/GOAL.md` (related_docs list)
- **Issue**: The "10 probes total split across positive/generalization/negative" claim is true of the **runtime** (`packages/cli/src/commands/e2e-evaluate.ts:138-251`, 4/3/4 split), but `e2e-evaluate.test.ts:55-83` only mocks 2 fake probes both with `kind: "positive"`. So `code-frozen-attestation` reading only the test source can prove `length === 10` but not kind composition.
- **Fix**: In `last-verified.md` cited the runtime line range explicitly. In `GOAL.md` `related_docs`, annotated which file carries which signal (runtime kind composition vs test asserts metrics).
