## TeamBrain 产品功能大全（49 项）—— 讲给可爱小鸭听

### 1. 核心学习闭环（9 项）🐣

鸭鸭说：系统要能**记录经验 → 编译规则 → 展示归因**，这样 AI 才不会重复踩坑！

| 功能 | 小鸭解释 |
|------|---------|
| 产品入口能打开 | 鸭总能看到菜单，不是空壳！ |
| 最小学习闭环 | 记录→编译→归因，演示跑得通 |
| AI 犯错前提醒 | AI 准备走错路时，系统提前拦住 |
| 纠正一次下次记住 | 用户纠正一次，AI 以后不犯同样的错 |
| 知识会自动进化 | 有用经验更可信，没用经验自动降级 |
| 看得见的统计 | 鸭总能看到学了多少经验、分布在哪些层 |
| 主动记录坑点 | 用户不用等 AI 犯错，可以自己先把坑记进去 |
| 安全沙箱 | 新改动先在隔离环境试，不污染主工作区 |
| 固定 canned answers | POSTPR/DOGFOOD/BUGREPORT/PRESHIP/FASTPROBE 规则稳定可用 |

---

### 2. 自动捕获 & 提取（3 项）🎯

鸭鸭说：AI 每次犯的错都要**自动抓住**，不要漏掉！

| 功能 | 小鸭解释 |
|------|---------|
| 自动捕获每次 session 的纠正 | Stop hook 全自动提取 |
| 真实 session JSONL 提取 judge | 召回率 ≥100% |
| 纠正检测器处理真实 JSONL 格式 | 各种奇怪形状都能解析 |

---

### 3. 校准器 v2（3 项）⚖️

鸭鸭说：知识要有**信任度评分**，不能所有经验都一个价！

| 功能 | 小鸭解释 |
|------|---------|
| 校准器发 `calibrator.adjustment` 事件 | 用户拒绝时自动降级信任 |
| Wilson LB + 5 层置信区间 | 统计上靠谱的评分算法 |
| 验证器发 `validator.failure` 事件 | 坏规则模式自动标记失败 |

---

### 4. 规则质量 & 匹配（5 项）🔍

鸭鸭说：规则本身也要**体检**，不能带病上岗！

| 功能 | 小鸭解释 |
|------|---------|
| 规则质量验证器 | 查 identical_patterns / confidence_range / missing_fields |
| embedding 冲突检测 | 两个规则太像会报警 |
| canned-answer 规则验证 | 规则本身也要验证 |
| Matcher B-055 词边界守卫 | 防止 wrong_pattern 乱触发 |
| Matcher 范围过滤 | file_types / paths glob 过滤正确 |

| sync pull 合并远程规则到本地 | 把别人的经验拉进来 |
